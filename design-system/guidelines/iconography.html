Icon roles follow type roles

Icons are functional glyphs, not identity marks. Use lucide-style stroke icons with semantic size roles that correspond to text density and interaction purpose.

Icon role
Typography counterpart
Use
icon-inline
.type-body-sm / .type-label
Inline labels, badges, form adornments. 16px, stroke 2.
icon-control
.type-label / button text
Buttons, menus, search controls. 18px, stroke 2.
icon-nav
navigation label
Sidebar and dock navigation. 18px, stroke 2 inactive / 2.4 active.
icon-status
status label
Semantic pills and alerts. 12-16px, state color, paired with text.
icon-launcher
compact launcher / avatar control
Coach update, next practice, header actions. 18px, stroke 2.4 inside a circular or avatar-style control.
icon-empty
empty/error state headline support
Empty states and error states only. 48px, low contrast, usually inside a quiet container.

viewBox="0 0 24 24" means the icon artwork is drawn on a coordinate plane that starts at x=0, y=0 and is 24 units wide by 24 units tall. The rendered size can be 16px, 18px, 48px, etc.; the browser scales the same 24-unit drawing into that physical box.
