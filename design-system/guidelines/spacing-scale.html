Density roles

Compact

Recruiter admin, QA and tabular views where information density wins.

Comfort

Candidate dashboard, setup and debrief surfaces with room for reflection.

Focus

Core session surfaces with enough air to reduce distraction.

System rule: use primitive tokens only to define semantic roles. Density changes the whole rhythm: edge padding, internal gaps, row spacing, type compactness and content volume. Product implementation should reach for intent tokens such as --gap-field, --pad-card, or --density-focus-gap before raw values.
