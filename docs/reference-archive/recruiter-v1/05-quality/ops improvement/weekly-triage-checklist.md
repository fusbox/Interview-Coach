# Weekly Triage Checklist

## Inbox

- [ ] Every new issue has `Type`, `Priority`, `Risk`, `Domain`, and `Stream`
- [ ] Inbox issues moved to `Ready`, `Backlog`, or closed

## Active Work

- [ ] `This Week` contains only a small number of active items
- [ ] Blocked items have a next step or explicit deferral

## Risk Review

- [ ] `Recruiter Hardening` view reviewed
- [ ] `Candidate Discovery` view reviewed
- [ ] privacy and security work is not buried by feature work

## Decision Hygiene

- [ ] Important decisions captured in docs
- [ ] Temporary TODOs either linked to issues or deleted

## Milestone Review

- [ ] Current milestone progress checked
- [ ] New work assigned to the correct milestone or stream
