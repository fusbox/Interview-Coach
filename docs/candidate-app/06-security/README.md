# Security And Privacy Docs

Use this folder for candidate Interview Coach privacy, disclosure, consent, retention, and security-risk artifacts.

## Start Here

- [Privacy, Disclosures, And Consent Requirements](privacy-disclosures-and-consent-requirements.md): product/legal implementation source of truth for notices, consent moments, policy gaps, candidate data visibility, cookies, AI disclosure, and retention posture.
- [Candidate App Threat Model](threat-model.md): engineering/security source of truth for assets, trust boundaries, attacker paths, mitigations, and manual review focus paths.

Do not create separate retention, consent, or disclosure docs unless the scope becomes large enough to justify a split. Add requirements to the privacy/disclosures artifact first, then reference them from implementation work items.
