# Subagent Assignment Template
Status: Reusable bounded delegation template

Use this for a subagent working inside a ratified autonomous milestone. The lead agent remains responsible for contract interpretation, shared-file ownership, integration, verification, and the final verdict.

## Objective

One observable investigation or implementation outcome.

## Required Context

- Active milestone:
- Governing contracts:
- Current repository evidence:
- Relevant V1/reference behavior to classify:

## Scope

- Read scope:
- Write scope:
- Shared files that are read-only:
- Worktree/branch:

## Prohibited Scope

- Product meanings that cannot change:
- Data/auth/privacy/provider boundaries that cannot change:
- Files and adjacent debt not owned by this assignment:
- Dependency, migration, commit, and push restrictions:

## Required Evidence

- Focused tests or inspection:
- Failure/recovery cases:
- Accessibility or responsive evidence:
- Data lineage or ownership evidence:
- Diff and documentation checks:

## Stop Conditions

- Contradictory canonical sources
- Required work outside the write scope
- New durable state, dependency, external service, or cost
- Security, privacy, identity, consent, retention, or provider-posture change
- Repeated failure beyond the assigned remediation budget
