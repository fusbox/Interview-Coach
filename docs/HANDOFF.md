### Slice 194 Autonomous Pilot Contract

**Outcome:** deliver one coherent production candidate experience over the existing V2 behavior contracts, beginning with shared shell and dashboard composition and continuing through the session surfaces only where the approved production design direction is sufficiently explicit.

**Canonical inputs:** [SPEC](./SPEC.md), [DATA_CONTRACT](./DATA_CONTRACT.md), [Question Preparedness](./04-architecture/question-preparedness-progress-contract.md), [Dashboard IA](./04-architecture/evidence-first-dashboard-information-architecture.md), [Production UI Workstream](./03-design/production-ui-workstream.md), [Design System Foundation](./03-design/design-system-foundation.md), current route/read-model tests, and the latest local Claude Design authoring snapshot for the reviewed production surfaces.

**Included:** shared candidate shell; dashboard hierarchy and role/prep-context control; coverage, question progress, Coach Update, Coach Plan, active-round, and follow-up-practice surfaces; responsive, keyboard, overflow, loading, empty, error, stale, and recovery states; compatibility-token retirement for replaced consumers; proportionate browser evidence.

**Excluded:** changing evaluator or preparedness meaning; changing persistence, ownership, launch, queue, or practice-intent contracts; recruiter or QA redesign; speculative new dashboard capabilities; credentialed profile promotion; deployment or release approval.

**Durable invariants:** UI consumes existing read/mutation contracts without duplicating derivation logic; prep-context selection remains stable and opaque-ID based; unanswered coverage remains distinct from achieved preparedness; latest feedback and highest-earned progress remain separate; candidate ownership, resume privacy, session recovery, and provider failure truthfulness cannot regress.

**Authority envelope:** the lead may decompose and execute reversible implementation slices, add focused semantic primitives, fix in-scope defects, and update tests/docs. Record small design-system extensions and bounded deferrals. Stop for altered product meaning, contradictory design references, new durable state, dependency additions, shared-file conflicts, material accessibility tradeoffs, provider-cost expansion, or any change to a security/privacy claim. No push or merge is implied by this contract.

**Acceptance:** focused component/route tests; complete candidate suite where shared behavior moves; typecheck, lint, optimized build, `npm run docs:check`; desktop and mobile browser screenshots for every replaced surface; keyboard/focus, overflow, loading/error/empty/recovery evidence; closing senior milestone verdict. The first internal slice map must be recorded before implementation begins.

- **Host acceptance:** run the real TA signed-token/network matrix; confirm issuer/source values, mint-per-click behavior, least-privilege MSSQL access, secret rotation, and upstream token-query redaction. RW is not enabled.
- **Provider and email operations:** obtain organizational approval for Gemini use/data handling; prove deployed audio, evaluator, wording, Coach Update, OCR, and SMTP behavior with telemetry and rollback ownership.
- **Operational containment:** wire alert sinks, parser/OCR resource containment, retention cleanup, deployed AI-eval worker recovery, key rotation, and access-log redaction for `/candidate/launch` and `/s/[token]`.
- **Dependency posture:** resolve or explicitly accept the current `@google/genai` cleanup-chain, Next/PostCSS, and Sharp/libvips advisories through tested upgrades; do not apply npm's regressive Next downgrade or untested overrides.
- **Security cleanup:** raw staging CSV discovery exports have been removed from the current documentation tree and are ignored under `docs/09-dev`; determine whether historical Git objects require separate remediation before release. Commit no new raw candidate/job exports.
- **Release evidence:** complete staging performance, manual accessibility, environment/rollback, post-deploy smoke, and a senior release pass. Local production-shell evidence is not a substitute.
